# Berlioz Admin 0.14.0

First public release, at `org.pageseeder.berlioz:pso-bzadmin:0.14.0`.
It is functionally equivalent to internal 0.14.0; distribution metadata, filenames, SBOM and signatures may differ.

## Features

Version 0.14.0 promotes the JAR-overlay beta series to stable distribution:

- Configuration and service inspection, load diagnostics and authorized scoped reloads.
- Optional EHCache 2, JCache and native Caffeine administration, with host-owned providers.
- Read-only PSML browsing, bounded log reading and source-level XSLT documentation.
- Application and JVM diagnostics, including live CPU, memory and cache-rate samples.
- Explicit host-granted `VIEW` and `OPERATE` permissions, guarded generators and same-origin POST operations.
- Responsive pages, keyboard navigation and documentation readable without JavaScript.

Since `0.14.0-beta.2`, changes are attribution and documentation cleanup, migration of the internal XSLT
helper namespace to PageSeeder, stable version/bundle metadata, and a Caffeine test-fixture timing fix.
The fixture now completes cache maintenance before asserting its weight; production cache behavior is unchanged.
There are no new administration features.
Earlier beta changes are recorded in the [release history](README.md#0140-beta2).

## Requirements and upgrade

Java 11, Berlioz 0.14.5 or later in the 0.14 line, a Servlet 4 (`javax.servlet`) container and a
host-provided XSLT 2.0 processor are required. Java 11, Jetty 10 and Saxon-HE 12 are the reference
configuration. Jakarta Servlet containers are unsupported; other JDKs and containers require qualification.
The host selects logging, cache and JSON providers and kickstart integration as described in the
[compatibility contract](../design/build-contract.md).

From `0.14.0-beta.2`, change the overlay dependency to `0.14.0` and redeploy with exactly
one overlay JAR. Access configuration and Java integration APIs are unchanged. Versioned JavaScript/CSS
filenames change to `bzadmin-0.14.0.min.js` and `bzadmin-0.14.0.min.css`.
From an earlier beta, also ensure Berlioz and kickstart are at least 0.14.5. From 0.13.x, remove the old
WAR overlay and its extracted resources before installing the JAR. See [upgrading and rollback](../guides/upgrading.md).

## Known limitations

- Java 11 and Jetty 10 are the reference test environment; Tomcat 9 and newer JDKs are not qualified.
- Includes of admin pages are denied. Avoid using admin URLs as container error pages; container-generated
  error responses can have different headers, and an error dispatch to an operation can execute it for an administrator.
- The fallback login has no rate limit; each incorrect password incurs a PBKDF2 computation.
- With container BASIC authentication, a POST without credentials can receive a Berlioz error document
  instead of a 401 challenge.
- JCache keys cannot be listed. EHCache 2 byte sizes and statistics reset are unavailable. Two registered
  JCache managers sharing a URI have no statistics. Cache keys are shown without redaction.
- Log contents and service generator parameters are displayed as supplied; they must not contain secrets.
- XSLT documentation describes source declarations: it does not evaluate `use-when` or load used packages.
- Kickstart may log a warning for XML responses when it selects the fallback stylesheet because
  `WEB-INF/xslt/xml/bzadmin.xsl` is absent.

separately from these user-facing notes.
